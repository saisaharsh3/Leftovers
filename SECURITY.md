# Security policy

Leftovers keeps people's financial data on their phones, so security reports are taken seriously.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/saisaharsh3/Leftovers/security/advisories/new)
with steps to reproduce and the app version (bottom of Settings).

You'll get a reply within a few days. Fixes ship in a new release, and you'll be credited in the changelog
unless you'd rather not be.

## Supported versions

Only the [latest release](https://github.com/saisaharsh3/Leftovers/releases/latest) gets security fixes.

## In scope

- Data leaving the device without the user's action, or being readable by other apps
- Weaknesses in backup encryption, app lock, or how API keys and email app passwords are stored
- The AI assistant changing data without confirmation, or being steered by text inside entries, SMS or email
